Beemy User Stories

63 stories, 30 screens, 11 two-week sprints, 16 Nov 2026 to 16 Apr 2027. The plan follows the TÜBİTAK 2209-A proposal “Kişisel Yapay Zekâ Asistanlarında Görev Devri ve Yetki Denetimi” (5 months, İP1–İP6).

One backlog, three places. Story ID, title, owner, sprint and screen number are the same in this doc, the Beemy Sprint Tracker and the Figma page Beemy — Görev Devri ekranları (v3). A screen story has the same name as its screen. Figma frames are named “NN · BM-xxx · Screen · Owner”. If this doc and the tracker ever differ, the tracker is right.

Team: Ezgi Kalfaoğlu is the project manager: documents, GitHub repositories and main, PR reviews, final report. She has no screens. Melike Şahin owns screens 01–10, Türkan Eda Uluçay 11–20, Ayşe Berfin Özçelik 21–30. “Shared” stories are done together.

Must keep: button texts, messages, where each button goes and the information the screen must show. Text in quotes is the exact Turkish text; the English text lives in en.json (BM-006). {x} is a value from the data. “X” → 05 means a tap on X opens screen 05. Free: layout and small visual details, as long as they follow the shared components on the Figma page.

Rules for every story: the language model only proposes actions; every state-changing call goes through the execution layer; payment, deposit, contract and data sharing are separate actions; every simulated action shows the badge “Simülasyon · sentetik veri”; no real person, business or account data; every screen has loading, empty and error states.

Definition of Done: merged to main through a pull request reviewed by Ezgi, every Must keep line checked, unit tests for logic files, works on iOS and Android, both languages checked, the screen matches its Figma frame.
